Tipos de seletores


Seletor de atributo

Permitem estilizar elementos com base na presença de um atributo ou no valor específico desse atributo. 

               input[required] (seleciona inputs que têm o atributo required).

Seletor Descendente

É representado pelo espaço em branco entre dois ou mais seletores, seleciona todos os elementos que são descendentes de um elemento ancestral específico. 

                ancestral descendente {
                    propriedade: valor;
                }

Seletor Filho Direto

É representado pelo sinal maior que e serve para estilizar apenas os elementos que são filhos imediatos de um elemento pai ignorando netos ou outros. 

            pai > filho {
                propriedade: valor;
            }

Seletor Adjacente Direto

É representado pelo sinal de mais e serve para selecionar um elemento que vem imediatamente após outro elemento específico 

                elemento1 + elemento2 {
                    /* estilos aqui */
                }

Seletor Irmão Gerais

É representado pelo símbolo de til, ele seleciona todos os elementos que aparecem depois de um elemento específico e comparilham o mesmo elemento pai. 

elemento1 ~ elemento2 {
                    /* propriedades CSS */
                }

Seletor de Pseudoclasse

É uma palavra-chave adicionada a um seletor que define o estilo de um elemento baseado em um estado específico ou em sua posição na página. 

                seletor:pseudoclasse {
                propriedade: valor;
                }

Seletor de Pseudoelemento

É uma palavra-chave adicionada a um seletor que permite estilizar uma parte específica ou criar elementos virtuais. 

                seletor::pseudo-elemento {
                    propriedade: valor;
                }
